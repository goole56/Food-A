## 2026-11-07 - Route-Level Code Splitting for Heavy Vendor Dependencies
**Learning:** Monolithic route imports in `src/App.tsx` bundle large disparate libraries (`@vis.gl/react-google-maps`, `jspdf`, `recharts`, `motion`) into a single initial JavaScript payload exceeding 1.36 MB (418 kB gzip), blocking First Contentful Paint even on lightweight auth routes. Lazy loading routes via `React.lazy()` with `<React.Suspense>` cuts initial entry bundle size down to ~408 kB (131 kB gzip) — an immediate 70% reduction in initial payload.
**Action:** When adding new top-level routes or heavy feature modules (like 3D Canvas models or report generators), keep route components dynamically loaded with `React.lazy` and export named or default components that allow bundlers to cleanly split vendor chunks.
