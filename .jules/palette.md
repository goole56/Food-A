## 2026-10-17 - Icon-only buttons accessibility pattern
**Learning:** Icon-only navigation buttons (e.g., Favorites, Shopping Cart, Dashboard, Logout) in header layouts lack accessible names unless explicitly assigned `aria-label` or `aria-labelledby`. Dynamic labels (like item count in cart) should be included in the `aria-label`.
**Action:** Always check navigation header icon buttons and ensure accessible `aria-label` strings are provided for screen reader users.
